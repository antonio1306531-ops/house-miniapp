# Mini App — простое приложение для бронирования

Это веб-приложение, которое открывается прямо внутри Telegram.

## Что умеет
- Красивый календарь (выбор заезда и выезда)
- Переключатель «Баня» (18:00–22:00)
- Форма имени и телефона
- Подсчёт стоимости
- Отправка заявки прямо в бота

## Как запустить (бесплатно)

### Вариант 1 — GitHub Pages (рекомендую)

1. Зарегистрируйся на [github.com](https://github.com) (если нет аккаунта)
2. Создай новый репозиторий, например `house-miniapp` (ставь Public)
3. Загрузи туда файл `index.html` из этой папки
4. Зайди в Settings → Pages
5. Source: Deploy from a branch → Branch: `main` → папка `/ (root)` → Save
6. Через 1–2 минуты появится ссылка вида:
   ```
   https://ТВОЙ-ЛОГИН.github.io/house-miniapp/
   ```
7. Эту ссылку вставь в файл `.env` бота:
   ```
   WEBAPP_URL=https://ТВОЙ-ЛОГИН.github.io/house-miniapp/
   ```
8. Перезапусти бота

### Вариант 2 — Netlify / Vercel
Просто перетащи папку `miniapp` на netlify.com или vercel.com — получишь HTTPS-ссылку.

## Важно
- Ссылка **обязательно** должна начинаться с `https://`
- После изменения `WEBAPP_URL` обязательно перезапусти бота
- В меню бота появится кнопка **«📱 Открыть приложение»**

## Как проверить
1. Открой бота
2. Нажми «📱 Открыть приложение»
3. Выбери даты, баня, имя, телефон
4. Нажми синюю кнопку «Забронировать» внизу
5. Приложение закроется, а в боте появится заявка

## Настройка цены и названия
В файле `index.html` найди строки:
```js
const PRICE_PER_NIGHT = 5000;
const HOUSE_NAME = "Загородный дом";
```
Измени на свои значения.
